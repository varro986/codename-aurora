Start the workflow for a new feature.

Argument: $ARGUMENTS (GitHub Issue number, e.g. "42")

Mandatory steps in order:

1. Load the `feature-spec` skill.
2. `gh issue view $ARGUMENTS` — read the User Story, acceptance criteria, and C# constraints from the Issue.
3. `git fetch --all` and check out the branch `feature/issue-$ARGUMENTS-*` created by the bootstrap workflow.
4. Read `tests/CodenameAurora.Tests.Unit/Issue$ARGUMENTSTests.cs` — this is the stub generated by the Action. Do not remove `[Skip]` until the plan is approved.
5. Load the `architecture` skill and answer the 5 pre-implementation questions.
6. Propose a plan: layer, new or extended interfaces, tests to implement, files to touch.
7. **Wait for explicit confirmation** before writing any `.cs` file.
