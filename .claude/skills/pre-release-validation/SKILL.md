# Pre-Release Validation

## When to use

- Before every `git push`
- Before opening a PR
- After completing a feature implementation

## Validation tiers

### Tier 1 — Quick (small or config-only changes)

```powershell
dotnet build [SLN] --configuration Release
dotnet csharpier --check .
```

### Tier 2 — Standard (before any push)

```powershell
dotnet build [SLN] --configuration Release
dotnet test [SLN] --configuration Release --results-directory TestResults/ --logger trx
dotnet csharpier --check .
```

### Tier 3 — Full (before PR / release)

```bash
dotnet build [SLN] --configuration Release
dotnet test [SLN] --configuration Release --results-directory TestResults/ --logger trx
dotnet test [SLN] --filter "Category=Architecture"
dotnet csharpier --check .
# Secret scan on staged files
git diff --staged | grep -iE 'password|secret|key|token|connectionstring|apikey'
```

## Checklist

### Code quality
- [ ] Zero build errors, zero new warnings (`TreatWarningsAsErrors` is on)
- [ ] All xUnit tests pass
- [ ] All architecture tests pass (`Category=Architecture`)
- [ ] `dotnet csharpier --check .` clean — no formatting drift

### Security scan
- [ ] No secrets in staged files (manual `git diff --staged` scan)
- [ ] `NO_HARDCODED_CONNECTION_STRING` smell rule clean (enforced at write time by hook)

### Git hygiene
- [ ] No untracked files that should be committed
- [ ] Commit message describes the WHY, not the WHAT
- [ ] Attribution: "Autogenerated with AI" — never `Co-Authored-By: Claude` (legal policy)

## Verification guard

`verification-guard.sh` (PreToolUse hook) blocks `git push` automatically when `.cs` files in the outgoing commits are newer than the last `.trx` test results. Run tests first to clear the block.

To bypass for non-source changes (docs, config, etc.):

```bash
SKIP_VERIFY_CHECK=1 git push ...
```

## Output interpretation

```
BUILD SUCCESSFUL in Ns   → proceed (check for new warnings)
BUILD FAILED             → blocking; fix before push

N tests, 0 failed        → proceed
N tests, K failed        → blocking; fix before push

csharpier --check: Formatted N files → run dotnet csharpier . then re-check
```
